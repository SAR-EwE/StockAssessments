# Baseline outputs (legacy script)

Reference outputs from the original `BAM2EwE age0 corr.R`, generated by
`legacy/BAM2EwE_age0_corr.R` from the rdats in `data/bam_rdats/`. Used as the
regression target while the code is refactored.

Regenerate from the repo root:

```bash
Rscript legacy/BAM2EwE_age0_corr.R
```

Generated 2026-11-05 with R 4.6.2.

## Agreement with the existing OneDrive outputs

Compared with the files in the OneDrive `BAM2EwE` folder:

- **All 10 per-species workbooks match numerically, sheet for sheet.** The
  `Biomass mt` sheets for red porgy, red snapper, snowy grouper and vermilion
  snapper on OneDrive (saved 2025-06-18) also have two extra, empty columns.
- **`indices.csv` and `indices_header.csv` are identical.**
- **`alternative M calcs.xlsx` differs for gray triggerfish and red grouper.**
  The OneDrive copy (saved 2025-12-03) was produced from the *old*
  `GTF_SEDAR41.rdat` and non-FES `RGRP_SEDAR53.rdat`. Re-running with those
  files reproduces it exactly. The baseline here uses the current SEDAR 82 and
  SEDAR 53 FES-update files.
- **`stock assessment Ecopath inputs.csv` has no OneDrive counterpart,** because
  the original script never wrote it (`dir.base` was undefined).

## Known bugs that are kept in the baseline on purpose

These will be fixed in the refactor, so the new outputs are *expected* to
differ from the baseline here:

- **Alternative M:** `t0` is always -0.5 (`dat$parms$t0<-1` assigns instead of
  comparing). The fix: use the assessment t0, or -0.5 when t0 < -1.
- **Ecopath inputs:** the `total` row of `BA.1985` and `BA.3yr` for
  multi-stanza species uses only stanza 1, because the matrix is indexed as a
  single vector.
- **Alternative M weight-at-length:** uses ad hoc multipliers to convert
  `wgt.a` to cm units (exact only when b = 3).
